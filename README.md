# MyJavaPerfection
This Java (17) project contains the best implementation I have ever wrote. It is a tech test I worked on that resulted in me having an in-person interview. I have made it flexible, I utilise the full extent of the language to the relevance of the project, but also off-load irrelevant functionality to 3rd party libraries.

It also has near full unit test coverage, utilising JUnit 5.

## Purpose
Given (alphabetical) text it will output each letter followed by the amount of times it appears consecutively. So an input of "Hello" will produce an output of "h1e1l2o1".

## How to use
The project was created in IntelliJ IDEA. I have created run configurations that cover all the ways the program can be run.

To manually run the program I have created the files "basicRun.bat/sh". Just add any flags/options to the end of the java line such as "--help".
